# Setup AI Assistant

Untuk setiap interaksi dengan AI (seperti Gemini, Antigravity, dll.) di proyek ini, **selalu** gunakan aturan berikut:

1. **Gunakan Graphify Rule:** 
   Selalu referensikan dan patuhi aturan di `@[.agents/rules/graphify.md]`.
   
2. **Gunakan Caveman Mode:**
   Selalu panggil perintah `/caveman` agar AI memberikan jawaban yang singkat, padat, tanpa basa-basi, dan langsung ke kode/solusi.
